Privacy Policy – Video Automation

Last updated: 14 November 2026

What the app accesses

When the channel owner signs in with Google, Video Automation requests these permissions:

  • youtube.upload: to upload videos the owner has produced to the owner's own channel.
  • youtube.readonly: to read the owner's channel name and confirm which channel is connected.

How data is used and stored

The OAuth refresh token is stored only on the owner's own server, in the app's configuration file, and is used only to upload videos to the owner's channel. No Google user data is sold, shared with third parties, or used for advertising. The app does not access data of any other Google user.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

The app uses YouTube API Services; see the Google Privacy Policy.

Removing access

You can revoke the app's access at any time at myaccount.google.com/permissions. On request the stored token is deleted.
